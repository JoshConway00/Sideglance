# Contributing

Open an issue to discuss substantial changes before implementing them. Keep changes focused and use fictional examples instead of personal Codex data.

Create a branch, make your change, and run `./build.sh` on an Apple Silicon Mac with a macOS 26 or newer SDK. This builds the app and runs the offline tests. Describe the problem, resulting behaviour, validation and remaining limitations in your pull request.

Do not commit credentials, task exports, quality logs, user preferences or build products. UI changes should include a sanitised screenshot when useful. Keep review discussions constructive and respectful.

The maintainer reviews and merges pull requests manually. Contributions are provided under the project's MIT licence.
